The fifth release candidate for v0.12.0 improves keyboard access and text contrast in Search.

These notes cover changes since v0.12.0-rc.4. There are no new breaking changes or cache-version changes; the critique contract remains at version 19. This is a pre-release and does not advance the stable `v0` alias. To test it, pin the deployment explicitly to v0.12.0-rc.5.

## Fixed

- **Fullscreen search keeps keyboard focus visible.** Tabbing through search could reach page controls hidden behind the overlay, and closing it did not restore focus. Search now starts in the input, keeps keyboard focus inside its fullscreen view, and restores the invoking control when dismissed. Keyboard and pointer result selection remain available.
- **Search placeholder text is readable in both themes.** The extra placeholder opacity reduced text contrast below 4.5:1. Placeholder text now meets the normal-text contrast requirement in light and dark themes.
