The prow-ai-dashboard is installed.

Worker:           {{ include "prow-ai-dashboard.fullname" . }}-worker (watch every {{ .Values.fetcher.watchInterval }}, reconcile every {{ .Values.fetcher.reconcileInterval }})
{{- else }}
Fetcher CronJob:  {{ include "prow-ai-dashboard.fullname" . }}-fetcher (schedule {{ .Values.fetcher.schedule | quote }}, suspended={{ .Values.fetcher.suspend }})

Server:           {{ include "prow-ai-dashboard.fullname" . }}-server
Shared volume:    {{ include "prow-ai-dashboard.pvcName" . }} ({{ .Values.persistence.accessMode }})

The server serves the SPA at / and the JSON contract at /data/*, with a
capability descriptor at /api/capabilities.

{{- if and (or .Values.server.actions.enabled .Values.server.chat.enabled) (eq .Values.server.actions.mode "oauth") }}
OAuth access:
{{- if .Values.server.actions.enabled }}
{{- if .Values.server.actions.oauth.privateRepositories }}
  Private-repository access is enabled. GitHub OAuth requests the broad repo
  scope. Use this only when an issue or fix target is private.
{{- else }}
  Actions use the public_repo scope. Set
  server.actions.oauth.privateRepositories=true only for private targets.
{{- end }}
{{- else }}
  Chat-only OAuth uses the read:user scope.
{{- end }}
  If this release previously requested repo and now uses public-only access,
  every admin must sign out and authorize the OAuth App again.
{{- end }}

{{- if .Values.ingress.enabled }}
Reach it at:
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
No ingress is enabled. Port-forward to try it:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "prow-ai-dashboard.fullname" . }}-server 8080:{{ .Values.server.service.port }}
  open http://localhost:8080
{{- end }}

{{- if eq .Values.mode "cron" }}
The fetcher runs on its schedule. To populate data immediately, create a Job
from the CronJob:

  kubectl --namespace {{ .Release.Namespace }} create job --from=cronjob/{{ include "prow-ai-dashboard.fullname" . }}-fetcher fetch-now-$(date -u +%Y%m%d%H%M%S)
{{- else }}
The worker populates data continuously. Follow its progress:

  kubectl --namespace {{ .Release.Namespace }} logs -f deploy/{{ include "prow-ai-dashboard.fullname" . }}-worker
{{- end }}
