The server serves the SPA at / and the JSON contract at /data/*, with a
capability descriptor at /api/capabilities.

Service origin:
{{- if eq $serviceType "ClusterIP" }}
  ClusterIP only. Place an in-cluster ingress or private origin in front of it.
{{- else if $internalEnabled }}
  Internal LoadBalancer requested through explicit provider annotations.
{{- else if and (gt (len $sourceRanges) 1) $publicAcknowledged }}
  WARNING: multiple LoadBalancer source ranges explicitly acknowledged. The
  chart cannot prove that their combined coverage is restricted.
{{- else if $sourceRanges }}
  LoadBalancer restricted by spec.loadBalancerSourceRanges.
{{- else if $publicAcknowledged }}
  WARNING: public LoadBalancer origin explicitly acknowledged. Confirm runtime
  reachability and restrict the origin whenever possible.
{{- else if eq $serviceType "LoadBalancer" }}
  LoadBalancer without an explicit chart-recognized origin restriction.
{{- else }}
  NodePort exposes the server on every selected node. Prefer ClusterIP or an
  explicitly restricted LoadBalancer for authenticated actions or chat.
{{- end }}
{{- if and (or .Values.server.actions.enabled .Values.server.chat.enabled) (not .Values.networkPolicy.enabled) }}
  Authenticated actions or chat are enabled while NetworkPolicy is disabled.
{{- end }}
  Service annotations are pass-through configuration, not proof that the
  origin is unreachable. Verify the deployed network path directly.

{{- if and (or .Values.server.actions.enabled .Values.server.chat.enabled) (eq .Values.server.actions.mode "oauth") }}
OAuth access:
  GitHub OAuth uses the identity-only read:user scope.
{{- if .Values.server.actions.enabled }}
  BOT_TOKEN performs issue and pull request writes. Scope that credential only
  to the configured action repositories and operations.
{{- else }}
  Chat-only OAuth does not mount BOT_TOKEN.
{{- end }}
  If this release previously requested repository access, every admin must sign
  out, revoke the old OAuth grant, and authorize the identity-only access.
{{- end }}
